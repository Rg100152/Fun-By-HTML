11. Formatting Tags

Formatting tags are used to style text with special meaning.

  • <b> / <strong> - Bold/important text
  • <i> / <em> - Italic/emphasized text
  • <u> - Underlined text
  • <mark> - Highlighted text
  • <small> - Smaller text
