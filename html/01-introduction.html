1. Introduction

HTML stands for HyperText Markup Language. It is the standard markup language for creating web pages.

Basic Structure

<!DOCTYPE html>
<html>
<head>
  <title>My First Page</title>
</head>
<body>
  <h1>Hello World!</h1>
  <p>This is my first page.</p>
</body>
</html>
